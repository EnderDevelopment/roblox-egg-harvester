# EggHarvester

This script collects eggs and brings them to your base, categorizing them by rarity. It is designed for Roblox games and provides a simple way to automate the collection and organization of eggs based on their rarity.

## Install

1. Download the script from the GitHub repository.
2. Place the script in your Roblox game workspace or a suitable location.
3. Configure the script by setting your base position and defining the egg types and their properties.

## Use

1. Place the script in your game.
2. Configure the egg types and base position in the script.
3. Run the script to start collecting and categorizing eggs.
